# SafeStep 서버 실행 방법

## 필요한 파일 (server/ 폴더 안에 있어야 함)
- `server.py`
- `bbox2.pt` — 객체 탐지 모델
- `surface.pt` — 노면 세그멘테이션 모델
- `.env` — ngrok 토큰 및 Gemini API 키

## .env 파일 내용
```
NGROK_AUTH_TOKEN=발급받은_토큰
NGROK_DOMAIN=발급받은_도메인
GOOGLE_API_KEY=발급받은_키
```

---

## 서버 켜기

```bash
cd server
python server.py
```

실행되면 터미널에 ngrok 주소가 출력됨 (예: `https://xxxx.ngrok-free.app`)

이 주소를 앱의 **서버 URL 입력창**에 붙여넣고 사용

---

## 서버 끄기

터미널에서 **Ctrl + C**

---

## 엔드포인트 설명

| 경로 | 기능 |
|------|------|
| `/detect` | YOLO 객체 탐지 (장애물, 사람 등) |
| `/segment` | 노면 세그멘테이션 (차도/골목/위험구역) |
| `/signal` | 신호등 색상 감지 (빨강/초록/점멸) |
| `/assistant` | 음성 AI 어시스턴트 (Gemini LLM) |
| `/health` | 서버 상태 확인 |

---

## 자주 발생하는 오류

**bbox2.pt 없음 오류**
→ `server/` 폴더에 `bbox2.pt` 파일 복사

**ngrok 연결 안 됨**
→ `.env`에 `NGROK_AUTH_TOKEN` 확인

**음성 어시스턴트 안 됨**
→ `.env`에 `GOOGLE_API_KEY` 확인  
→ `pip install langchain langchain-google-genai langchain-core`
